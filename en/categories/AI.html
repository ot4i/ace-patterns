IBM App Connect Enterprise Patterns

AI Patterns

The AI Patterns category provides intelligent integration solutions that incorporate artificial intelligence capabilities into message flows. These patterns enable you to enhance business logic with AI-powered decision-making, natural language processing, predictive analytics, and data enrichment. Each pattern demonstrates how to integrate AI services or models—such as machine learning APIs, large language models, or custom AI engines—into your flows using supported protocols and formats. You can use these patterns to:

  • Analyze and classify incoming data
  • Generate intelligent responses or summaries
  • Extract entities or sentiments from text
  • Predict outcomes based on historical data
  • Enrich messages with external knowledge

This category includes patterns that connect to popular AI platforms (e.g., IBM Watsonx, milvus, pinecone) and demonstrate integration via REST APIs, Kafka, HTTP, and other supported protocols. Each pattern focuses on a specific AI use case and provides a reusable template for building smarter integrations. To use a pattern, select a relevant pattern from the Patterns Explorer in the Integration Toolkit. The Patterns Explorer provides a catalog of patterns and provides help. The help guides pattern users towards a pattern to use to solve a problem.
